6.¿Qué hace mejor GitHub Desktop que la terminal, y qué no puede hacer? ¿Con cuál habéis entendido mejor el conflicto?
Mejor en Desktop: ver los cambios en verde y rojo, el historial fácil y todo con botones, sin comandos.

No puede: aprobar o fusionar PR (web), dibujar el grafo de ramas ni comandos como git rm --cached (terminal).

Conflicto: en Desktop es más fácil de resolver porque te guía; en la terminal se entiende mejor qué pasa.
